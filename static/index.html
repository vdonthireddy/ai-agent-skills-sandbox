How It Works Under the Hood

The Agent Loop

An AI agent works by running a continuous loop. Instead of answering immediately, it reads the system prompt and available tools. It outputs a Thought (explaining its plan) followed by a Tool Call (a JSON request to execute a specific function). The python backend runs the function, appends the result, and feeds it back to the LLM to continue planning until a final answer is achieved.

Try this: Run the "Weather + Calculation" query and watch the flowchart glow move between the Planner and Skill Executor.

Built with pure Python (FastAPI) & Vanilla Javascript. No heavy frameworks (LangChain/CrewAI) used, illustrating the core logic of Agent-Tool loops.
